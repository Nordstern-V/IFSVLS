# PEFSL C124 PC 现场学习与识别程序

识别代码与发送者保留的C124一致，附带2026-10-25的W保存文件名修复。包括完整的学习、识别、身份核验、跟踪恢复、保存加载及诊断功能。这是Windows PC源码验证包；不是免安装EXE，也不是FPGA板端部署包。

## 首次安装和启动

1. 解压整个压缩包到可写的短路径，例如 D:\PEFSL_C124。不要在压缩包中直接运行。
2. 安装64位Python 3.12，安装时保留Python Launcher（py）。
3. 联网双击 install.bat，安装本目录独立环境。成功后双击 start.bat。
4. 首次导入PyTorch需要等待；默认摄像头0、CPU运行。安装脚本不会自动启动程序。
5. 若已有Python环境及下列依赖，也可在包目录执行 python launch.py。

实际打包环境：Python3.12.10、torch2.6.0+cpu、numpy2.5.3、opencv-contrib-python5.0.0.93、Pillow12.3.0。依赖联网安装，不随包携带；不要同时在该环境安装opencv-python或headless替代contrib版。

## 学习和识别

点击摄像头窗口使其获得焦点，使用英文输入法。按键字母不区分大小写。

- a：学习。鼠标左键框选实物需要学习的区域，输入标签并完成采集；同一标签可以继续补充不同姿态。没有随包携带个人学习数据，首次使用需自己学习。
- b：识别。目标是识别现场学习过的物体；学习某一实例不代表已经识别所有同类实例。允许只框住学习过的部分。
- w：保存到data目录，生成新快照，保留旧库。已修复连续保存时文件名不断增长的问题。
- l：加载启动时选定的学习库。下次启动会选择data目录中最新的learning*.npz，仍需按l加载，再按b识别。
- d：把当前原图、带框图及diag.txt保存到diagnostics目录。
- s：切换自动定位；c：清当前框；r：清空当前内存学习内容（已有磁盘快照仍保留）；q/Esc：退出。

学习结果需按w保存，未保存就退出会丢失本次内存学习。需要连续使用已有学习成果，重新打开后先按l。搬运数据请复制整个data目录并保留原件。

可以明确指定摄像头或学习文件：

```bat
start.bat --camera-id 1
start.bat --save-path "D:\my_data\learning.npz"
```

## 请队友验证什么

分别记录：类别是否正确、框是否覆盖学习区域、首次出框秒数、转动/移动后的恢复时间、移走后的残留和背景误框。出框帧数不是准确率。

程序当前仍可能首次识别慢、转动后漏检或恢复慢，尚未证明任意复杂物体或同类不同实例都有一致效果。请先记录原表现，不先降低阈值。

发现问题时：按d存诊断；按w保存对应的学习库；同时记录所用快照文件名。若录屏，将录屏、diagnostics与当时data快照配套提供，避免用不同学习阶段的数据复算。控制台[perf]/[backbone]等日志可一并保留。

## 包内容与检查

包含bbox_demo.py、全部PC运行依赖模块（含bbox_parts.py和bbox_storage.py）、原ResNet9权重、骨干及分类模块、许可证、安装/启动脚本和VERSION.json。没有个人NPZ、照片、录像、历史候选或只读诊断版。

VERSION.json记录每份运行源码和权重SHA256。可在安装后核验：

```bat
.venv\Scripts\python.exe verify_package.py
```

无摄像头基本自检：

```bat
.venv\Scripts\python.exe launch.py --self-test
```

自检只检查打包后依赖、模型与基本学习分类和内存序列化，不能代替现场识别或板端帧率验收。接收者电脑的依赖安装、摄像头和实际识别表现仍需现场验证。

摄像头连接失败时先确认没有重复窗口或其他程序占用摄像头，再检查物理开关、Windows摄像头权限及设备编号。请保留报错文本以便定位。
