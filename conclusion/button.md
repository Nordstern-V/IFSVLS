# LCD 按键使用说明

## 通用按键

| 按键 | 功能 |
|---|---|
| **A** | 进入学习模式，画框后选择类别学习物品。 |
| **B** | 进入识别模式，自动扫描或手动画框识别已学习物品。 |
| **D** | 进入数字、算符识别与计算模式。 |
| **SAVE** | 保存当前已学习的物品及名称，供下次使用。 |
| **LOAD** | 恢复已保存的物品学习数据及名称。 |
| **CLEAR** | 清空当前已学习物品，不删除已保存文件，也不清空计算式。 |

## A / B 模式按键

| 按键 | 功能 |
|---|---|
| **1** | A 模式下，将框内物品学为类别 1。 |
| **2** | A 模式下，将框内物品学为类别 2。 |
| **3** | A 模式下，将框内物品学为类别 3。 |
| **4** | A 模式下，将框内物品学为类别 4。 |
| **SCAN** | B 模式下，开启或关闭自动扫描。 |

学习前先画框；如输入了物品名称，先按键盘 Enter 确认，再点类别按钮。B 模式手动画框会暂停扫描，点 SCAN 可恢复。

## D 模式按键

| 按键 | 功能 |
|---|---|
| **OP MODE** | 点亮时识别算符，关闭时识别数字。 |
| **FREEZE** | 冻结当前画面，便于画框识别和存入。 |
| **LIVE** | 解除冻结，恢复实时画面。 |
| **X1～X10** | 将当前识别出的一个数字存入下一个数字位置。 |
| **OP1～OP9** | 将当前识别出的算符存入下一个算符位置。 |
| **UNDO** | 撤销最后存入的一项，随后需重新画框。 |
| **RESET** | 清空计算式和结果，随后需重新画框。 |
| **OUT** | 计算当前完整表达式并显示结果。 |

存入前先点 FREEZE，框住一个数字或算符，等 **READY** 后核对结果再存入；按“数字 → 算符 → 数字”顺序操作，每次存入后重新画框。

Xn、OPn 的编号会自动变化；显示 **X FULL / OP FULL** 表示对应位置已满，最多可存 10 个一位数字和 9 个算符。切换模式或 FREEZE/LIVE 会保留计算式，退出程序后不保留。
