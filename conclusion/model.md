# PEFSL_MIX_PLUS 功能模块清单

整理日期：2026-11-02；当前应用版本：`mix-plus-ab-r17-20261101-r21-keyboard-calc10`。

结合 `conclusion.md` 与当前活动源码，按功能职责划分为以下 32 个模块，每个模块用一句话说明其作用。

## 一、应用与交互功能

| 序号 | 功能模块 | 功能简述 |
|---|---|---|
| 1 | 实时画面与 LCD 界面 | 在 800×480 LCD 上显示摄像头画面、操作按钮、目标框、类别名称和识别结果，并管理 A/B/D 模式切换。 |
| 2 | 触摸交互与 ROI 框选 | 将触摸按下、移动和松开事件转换为按钮操作及单个目标区域的拖动框选。 |
| 3 | A 模式少样本学习 | 对框选物体默认连续采集 8 帧特征，存入类别 1～4 并更新该类别的支持样本。 |
| 4 | B 模式手动持续识别 | 对手动框选区域定期重新分类，并在目标框上方显示已学习物体的名称和分数。 |
| 5 | B 模式自动扫描 | 使用多尺度窗口轮换搜索画面中的已学习物体，并支持 SCAN 开关及手动框选后的暂停与恢复。 |
| 6 | USB 键盘类别命名 | 在 A 模式输入由英文大小写、数字、空格或下划线组成的最长 24 字符名称，实时显示并在确认和采样成功后关联类别。 |
| 7 | 学习数据管理 | 通过 SAVE、LOAD、CLEAR 保存、恢复或清空 A/B 的特征、类别、框尺寸、颜色统计和名称数据。 |
| 8 | D 模式数字识别 | 使用独立数字支持库识别框选区域中的单个 0～9 数字，不占用 A/B 的四个物体类别。 |
| 9 | D 模式算符识别 | 切换 OP MODE 后使用独立算符支持库识别加、减、乘、除四类符号。 |
| 10 | 画面冻结与字形预览 | 通过 FREEZE/LIVE 固定或恢复实时画面，并按配置显示 32×32 二值化字形预览以辅助框选。 |
| 11 | 候选确认与表达式编辑 | 将稳定且有效的屏幕候选存入 Xn/OPn，支持最多 10 个一位数字和 9 个算符，并提供 UNDO、RESET 及重复存入保护。 |
| 12 | 四则运算与结果显示 | 在 PS 端按先乘除后加减计算已存表达式，通过 OUT 显示结果并处理空表达式、不完整表达式及除零。 |

## 二、算法与硬件支撑功能

| 序号 | 功能模块 | 功能简述 |
|---|---|---|
| 13 | ROI 图像预处理 | 将目标区域裁剪、缩放为 32×32 图像，并按现有模型约定完成特征提取前的数值预处理。 |
| 14 | 数字与算符字形预处理 | 对字形 ROI 进行灰度化、二值化及形态处理，并检查无效输入以减少背景和旧候选干扰。 |
| 15 | 少样本 NCM 分类 | 根据支持样本的特征均值、居中归一化及距离关系，为查询图像生成类别预测和类间分数。 |
| 16 | 扫描候选筛选与确认 | 结合余弦匹配、类别分差、尺寸、中心与周围颜色差、可选颜色门限及重叠抑制和跨周期确认筛选扫描结果。 |
| 17 | 数字与算符支持库 | 分别构建、加载和检查数字及算符的 TCU 特征缓存，并提供自匹配和留一评估。 |
| 18 | TCU 硬件特征提取 | 在 PL 的 Tensil TCU 上运行现有 ResNet 模型，为学习、识别和扫描提供 80 维视觉特征。 |
| 19 | TCU 数据适配与 DMA 驱动 | 完成 12 路输入打包、模型运行及 DMA 对齐，并将 84 个输出值按模型分段整理为 80 维特征和 4 个诊断值。 |
| 20 | 摄像头采集与视频传输 | 通过 OV5640、PL 视频通路、VDMA 和 DDR 缓冲完成摄像头帧的采集、传递及 LCD 视频输出。 |
| 21 | 触摸 IIC 与 GPIO 驱动 | 通过 AXI IIC 访问触摸控制器，并使用 GPIO 管理 INT、RESET、坐标读取和触摸事件生成。 |
| 22 | USB Host 与键盘输入 | 通过 USB Host 枚举键盘并读取 evdev 事件，完成复合接口筛选、字符解码、独占访问及热插拔重连。 |
| 23 | 7020 板级 PS/PL 平台 | 为领航者 7020 配置 PS、DDR、AXI 互联、时钟、复位及外设管脚，承载视频、TCU 和触摸硬件。 |

## 三、运行保障功能

| 序号 | 功能模块 | 功能简述 |
|---|---|---|
| 24 | Overlay 与模型初始化 | 使用同一个 Overlay 初始化视频、触摸和 TCU，并加载匹配的 HWH、模型及驱动资源。 |
| 25 | TCU 后台任务调度 | 在单个后台工作线程中串行执行学习、手动识别、扫描及 D 模式任务，减少模型调用对界面刷新的阻塞。 |
| 26 | 触摸看门狗与自动恢复 | 将 IIC 调用隔离在独立进程中，监测心跳并在异常时执行复位、进程重建和控制器重新初始化。 |
| 27 | 输入事件同步与状态保护 | 按时间顺序合并触摸和键盘事件，并在模式、ROI 或输入状态变化时取消不再有效的命名及识别候选。 |
| 28 | 运行状态与故障诊断 | 在串口输出版本、帧数、模式、触摸健康状态和恢复计数，辅助定位运行卡顿与设备异常。 |
| 29 | 安全退出与资源清理 | 响应 Ctrl-C 或运行时限，停止工作线程和进程并释放视频缓冲、键盘设备及其他运行资源。 |

## 四、工程构建与维护功能

| 序号 | 功能模块 | 功能简述 |
|---|---|---|
| 30 | 硬件构建与部署交付 | 通过 Tcl 和 Vivado 工程生成匹配的 bitstream/HWH，并按硬件、触摸、TCU 和应用目录组织板端部署。 |
| 31 | 模块验证与软件回归 | 通过触摸、键盘、TCU 特征验证脚本及应用回归测试，检查接口、交互状态和版本兼容性。 |
| 32 | USB 启动修复与回退 | 对匹配镜像修复 USB Host 设备树，执行哈希校验、启动文件备份和恢复操作。 |
