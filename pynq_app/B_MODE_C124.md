# B 模式 C124 移植（2026-10-31，r18）

基于 `PEFSL_C124` 的普通物体注册与识别流程，移植适合 PYNQ 的有界实现。
继续使用已有 bit/hwh、80D TCU 特征和 r16 触摸进程恢复。数字、运算符、
冻结画面和计算器使用原来的 D 模式分类路径。

## 部署和首次使用

将本工程 `pynq_app` 的以下五个文件同时更新到板端同名目录：

- `pefsl_touch_ui.py`
- `pynq_bbox_demo.py`
- `pefsl_bmode.py`（新增）
- `pefsl_identity.py`（新增）
- `pefsl_proposals.py`（新增）

保留原有 `pefsl_scan.py`、数字/运算符模块和缓存；无需重新生成 bitstream、
tmodel 或数字/运算符缓存。

```bash
cd /home/xilinx/jupyter_notebooks/PEFSL_MIX_PLUS/pynq_app
sudo -E /usr/local/share/pynq-venv/bin/python3 pynq_bbox_demo.py
```

启动应打印 `UI version: mix-plus-bmode-20261031-c124-r18`。

**完整的新身份核验需要在新版 A 模式重新学习并 SAVE。** 每次框选尽量贴合
完整学习区域，在八次采样结束前保持该物体在框中。同一类别可再次框选学习
其他姿态；每类保存最多四张差异较大的 48×48 完整区域小图。原学习文件仍可
LOAD；没有参考小图的旧类别只走兼容特征/颜色路径，不能获得新增纹理核验。
代码部署不会替换已有 `pefsl_learned.npz`；SAVE 才会写学习文件，升级前可自行
保留旧学习文件副本。

切到 B 自动扫描，或在 B 手动画 ROI。手动和扫描使用同一拒识链：
特征余弦 → 多视图颜色 → 弱形状门 → 完整 ROI 的分布式注册纹理核验。
不支持的物体显示 `B no match (...)`，不再强制选一个已学习类别。显示的
`sim=...` 是余弦相似度，不是识别正确率或校准概率。

## 与 C124 对齐的行为

- 新注册使用原始特征单位化后的 Top1/Top5 聚合余弦，避免正样本均值消除
  单类身份。兼容库继续使用居中空间；新增原始空间类别前冻结旧类别中心。
- 每个学习视图分别生成颜色直方图，任意视图支持即可；低饱和类别忽略不稳定
  的 hue。沿用板端 16×8×4 bins，不把电脑端 8×8×8 数据直接混入。
- 纹理需要完整区域相关性和至少四个分布块共同支持；小 logo、单条边缘或
  相同颜色不能单独确认身份。缓存仅保存注册数据，不缓存当前目标的得分。
- 框外环带不自动当作负样本：C124 的新注册同样不信任这种背景，避免物体
  边缘被错误当成负类。
- 自动候选包括轮换网格、当前图像轮廓/Lab 连通区域、待确认位置及近邻。
  所有候选都要通过同一核验链。区域分析只在推理 worker 中执行一次/周期。
- 优先回访到期目标，最多连续两次局部检查后留一次全局窗口；相近位置需要
  两次独立当前图像核验才显示，无须等待两个完整全局扫描周期。单周期结束
  不重复计算确认次数。
- 超过 1.5 秒的 B 结果丢弃；直接回访失败立即撤销该框；超过 3 秒没有有效
  核验的显示框过期。新 ROI、LOAD 和模式切换都会阻止旧请求发布。
- 明显平坦背景可以在 TCU 前过滤。较重的纹理核验在 UI 状态锁之外执行，
  继续保持唯一串行 TCU worker。

## 参数与观察

默认 `--scan-cos-th 0.56` 同时用于手动 B 和扫描，不建议先降低门限。
`--scan-confirm-hits 2` 控制独立核验次数（旧名 `--scan-confirm-cycles` 仍接受）。
`--scan-hist-th` 是额外的直方图交集下限；值为 0 不关闭 C124 基础颜色核验。
如果终端反复显示 `stale result discarded`，先记录 TCU 耗时；必要时使用
`--b-max-result-age 3`，范围 0.1~30 秒。不要通过放宽身份门解决 IIC 问题。

每周期终端 `reject={...}` 会统计 feature、colour、identity、flat 等拒绝原因。
验证时分别测试：旧库 LOAD、新版 A 单类学习、背景移空、同色不同物体、已学
物体重新放入、B 手动框、扫描、多类别、A/B/D 切换及 D 运算符/计算器。

## 验证范围与限制

主机测试使用假 TCU，实际执行了存储、预处理、身份核验、UI 和异步状态流，
并回归数字/运算符/计算器。另检查 Python 3.8 语法。测试不能替代实板准确率、
扫描恢复时间或 ARM 帧率验收。

为了控制 ARM 开销，未照搬 C124 的 ORB/单应性、密集光流、透视恢复和长参考
库搜索。当前纹理核验支持适度亮度变化、小平移和 90 度旋转；大角度透视、
形变或新物体表面需要补充学习视图。纯色、无可辨纹理的注册区域会被保守拒识，
可改为框选包含物体轮廓/标记的稳定完整区域。该版本不能承诺与 PC C124 相同
的召回率，实板测试后才可确认改善幅度。
