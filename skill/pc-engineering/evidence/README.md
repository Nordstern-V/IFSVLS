# 证据摘要说明

`evaluation_summary.csv` 从已有 C196 与 C207r2 串行回归的 6 份结果中提取，共 22 条；源文件名与 SHA-256 记录在 `source_hashes.json`。原脚本把修订版标签写成 `C207`，该表中的 `C207` 指的就是 `C207r2`。

字段说明：

- `learning_stage=two` 是玩偶与涂改带的两类学习阶段；`cup` 是另外的水杯学习阶段，两者未混用。
- `first_formal_by_class_seconds` 是该次观察中类别编号到首次正式显示时间的映射；`{}` 只表示观察时段内没有正式框，不代表已完成逐帧正确性标注。编号 `1` 在两类学习阶段对应玩偶，编号 `0` 在水杯阶段对应水杯。
- `as_loaded=True` 表示直接使用存档加载值；`False` 表示按已有回放流程在内存中恢复长宽比精度，以匹配该阶段实时指纹，没有写入或覆盖学习库。
- `screen capture with overlays` 代表带旧框和文字的屏幕录像；`background control` 代表构造的背景控制画面，可能含遮罩或处理痕迹。

此摘要不包含原图、录像、学习库、程序或完整原始日志。源文件名只用于与队内存档对应；要让外部人员独立复现，须另行提供获授权的完整数据、工程和环境。摘要不能单独推算准确率、召回率或 FPGA 性能。
